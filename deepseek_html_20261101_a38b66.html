openport

free persistent tcp & udp port forwarding to localhost.

"Close the world, Open the nExt."

install & download

run in your terminal or download the GUI desktop client:

linux / mac:
curl -sSL https://openport.pw/install.sh | bash
windows powershell:
iwr -useb https://openport.pw/install.ps1 | iex
windows cmd:
curl -sSL https://openport.pw/install.cmd -o "%temp%\install.cmd" && "%temp%\install.cmd"
or download windows gui app:
OpenPort GUI (Desktop Interface for Windows) download .exe

standalone Windows client with a graphical user interface. No terminal required — simply enter your local port and start forwarding with a single click.

prompt for cursor, claude, windsurf or chatgpt:
Install OpenPort from https://openport.pw, expose port <PORT>, and give me the public URL.

paste into Cursor Composer, Claude Code, Windsurf, or Copilot. The AI will detect your OS, install the lightweight client, tunnel your local port in the background, and provide the live link. No signup or tokens required.

commands

openport <local_port> forward local port to the internet (e.g. openport 8080). prints your public port.
openport info show assigned permanent port and secret token.
openport link <id> <tok> link your existing port to another computer.

features & use cases

  • zero signup no registration, no credit card, no email required. run the install script and you immediately get a port.
  • privacy & 0 logs oriented towards user privacy. We do not collect personal data, do not track anything, and enforce a strict 0 logs policy.
  • dual tcp & udp simultaneous TCP and UDP forwarding on the same port. ideal for game servers (Minecraft, Valheim), voice services, and raw sockets.
  • permanent port your assigned public port stays with you across restarts. no broken webhook URLs or reconfiguring configs every run.
  • cgnat bypass works behind carrier-grade NAT, hotel Wi-Fi, strict enterprise firewalls, and home routers without manual port forwarding.
  • native rust core powered by Rathole with TCP_NODELAY and BBR congestion control for minimal latency and line-rate throughput.

faq

how is openport funded?

OpenPort is an independent project funded entirely through voluntary crypto donations from users. We need ~$50/month to keep the high-speed gigabit servers, DDoS mitigation, and domain running smoothly. You can support the project in the donation section above.

how is openport different from portmap.io?

portmap.io requires generating and running an OpenVPN client with configuration files. OpenPort needs no VPN or configuration: just run a single lightweight command to tunnel any local port.

how do i host game servers (Minecraft, etc.)?

run openport 25565. Friends can join using openport.pw:<your_assigned_port>. Both TCP and UDP are enabled by default.

does it work behind router / CGNAT?

yes. The client creates an outbound encrypted reverse tunnel to openport.pw, completely bypassing NAT, CGNAT, and firewall restrictions without touching your router.

does openport track users or keep logs?

no. OpenPort is oriented towards user privacy. We do not collect personal data, do not track anything, and enforce a strict 0 logs policy. Tunnel traffic is never inspected, monitored, or recorded.

how do i report abuse or illegal content?

we enforce a strict zero-tolerance policy against malware, phishing, botnets, and illegal activity. If you detect abusive or unlawful traffic on any openport.pw port, report it immediately to abuse@openport.pw with the port number. Abusive tunnels and accounts are permanently terminated.
